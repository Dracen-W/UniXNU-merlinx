merlinx Stage 7A：可用内存 + 256 MiB 读写测试
==============================================

结果（2026-10-23）：真机通过。256 MiB test at 0xC0000000 passed，
之后正常进入 UniXNU 菜单。

为什么先做这个
--------------
- merlinx DTS 其实已经在 uefi-merlinx/Resources/DTBs/merlinx.dts 和 .dtb；
  设备仓库里还没有对应副本，但当前启动镜像已经有 DTB 可用。
- eMMC 主要影响后面的 root/userland，不影响先验证内存。
- 当前 UEFI 只暴露 UEFI FD、DXE Heap 等少量 RAM，XNU 需要更多内存。
  所以先把 /proc/iomem 里的可用 System RAM 加进 GCD，并做 256 MiB 测试。

改动
----
在 MerlinxBootMemoryDxe 里加了 mAvailableMemory 表，把 /proc/iomem 中
确认是 System RAM、且不属于 FD、DXE Heap、FDT、initrd、ATF、TEE、MD、
pstore、SCP、SSPM、framebuffer 的范围加入 GCD：
- low gaps around initrd/FDT
- 0x4D100000-0x6FFFFFFF 附近
- 0x77000000-0x7CDAFFFF
- 0x7FE00000 起的高段
- 0x80000000-0xADFFFFFF
- 0xBE300000-0xBFFFEFFF
- 0xC0000000-0xFEFF5FFF
- 0x100000000-0x119FFFFFF

DEBUG 镜像还会在 0xC0000000 分配 256 MiB，写入/读回 pattern，
然后释放。Release 不包含这段测试（#ifndef MDEPKG_NDEBUG）。
