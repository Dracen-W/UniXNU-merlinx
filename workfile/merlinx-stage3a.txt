merlinx Stage 3A：FAT payload 卷 + unixnu.toml
================================================

目标：先验证 UniXNU 能从 FAT payload 卷读取配置和菜单条目。
这一步不需要 XNU 内核，也不需要 merlinx DTS；DTB 继续使用
workfile 里提取的 118,916 字节 trimmed DTB。workflow 没有改，
仍然是 sheng 的模板。

FAT payload
-----------
workfile/merlinx-stage3a-fat.img
4 MiB FAT12, label UNIXNU
/EFI/UniXNU/unixnu.toml
SHA256: 4110041f72725c01b631bbd7900770d329a6fae297b4a52f3080ec5f6bf77ac1

配置内容：3 个 action 条目（Stage 3A、Restart、Power off），
timeout 30 秒，default = "stage3a"。

镜像
----
out/merlinx-uefi-stage3a.img
size: 67108864 (64MiB, p33)
SHA256: 5bcc817878e9a1ebba1262b65d7dd6acdd5ae0f820f1924e76918db1dd802826
FD: 5880b1e8fc2ef6bb6ab67e76f988383784391fd888462ebb4e3f4fd092868e4c

刷入
----
fastboot flash boot /workspaces/UniXNU---merlinx/out/merlinx-uefi-stage3a.img
fastboot reboot

预期
----
默认不按键进 UniXNU，日志应出现：
UNIXNU: config: loaded \EFI\UniXNU\unixnu.toml
UNIXNU: menu: shown 3 entries, default 0 'stage3a', ...
并且菜单标题是 "UniXNU / merlinx"。

如果显示 built-in configuration，说明 UniXNU 没从 FAT 卷读到
\EFI\UniXNU\unixnu.toml；把 UNIXNU: 的 config 行发我。

注意
----
- 这不是 Stage 3 的 XNU payload；只是配置卷验证。
- 真正的 Stage 3 还需要 merlinx DTS 和 macOS/Xcode 产出的 kernel/ADT。
- workflow 仍是 sheng 模板，后续如果需要 CI 再单独改。
