merlinx Stage 2B：FAT ramdisk + FAT probe
=========================================

结果（2026-10-23）：通过。真机看到 Fat 安装和 HELLO.TXT 读取，
说明 LK -> GCD -> BlockIo -> DiskIo -> Fat 整条链正常。
FAT probe 是临时 DEBUG 代码，已经从工作树移除，只保留补丁。

在 BootMemoryDxe 里临时加了 DEBUG-only 的 FAT 自检：
- 注册 gEfiSimpleFileSystemProtocolGuid 的 protocol notify；
  Fat 安装 SimpleFileSystem 时立刻触发 probe
- 另加一个每 2 秒触发的 periodic timer 作为 fallback，
  直到找到 HELLO.TXT 后取消
- 枚举所有 SimpleFileSystem，打开 \HELLO.TXT 并打印内容
- 打印后 Stall 3 秒，方便看屏幕日志
Release 构建不包含这段（#ifndef MDEPKG_NDEBUG）。

刷入
----

fastboot reboot

先看到：
MERLINXMEM: initrd block device ... size 0x400000
MERLINXMEM: FAT notify Success
MERLINXMEM: FAT timer Success
紧接着 Fat 驱动安装 SimpleFileSystem，会触发：
MERLINXMEM: FAT filesystems 1, Success
MERLINXMEM: HELLO.TXT 31 bytes: hello from merlinx FAT ramdisk
（然后 Stall 3 秒）
如果 notify 没触发，每 2 秒的 timer 会再试；找到 HELLO.TXT 后自动取消。

如果看到 HELLO.TXT，说明 LK -> GCD -> BlockIo -> DiskIo -> Fat 整条链通了。
如果 FAT filesystems 0 或 HELLO.TXT not found，把那段日志发我。
